# robotics-turtlebot3

Syarat: Docker Engine >=24 dan Docker Compose >= v2.20. ROS tidak perlu dipasang di host.

```bash
git clone [https://github.com/Rangga-05/robotics-turtlebot3.git](https://github.com/Rangga-05/robotics-turtlebot3.git)
cd robotics-turtlebot3/docker
docker compose build
docker compose up
```
